# MDS ID Studio

MDS ID Studio is a student ID card generator website built with HTML, CSS, and JavaScript. Users can enter student details, generate a roll number, choose an ID card template, upload a photo, and create front and back ID card pages.

## Features

- Student details form
- College name input
- Photo upload
- Automatic roll number generation
- Front and back ID card page
- Multiple ID card templates
- Print ID card option
- Responsive design for PC and mobile

## Templates

- ACE College Blue
- Classic Green
- Modern Blue
- Dark Premium
- Neon Tech
- Royal Purple
- Minimal White
- Sunset Orange

## Project Files

```text
index.html   - Main website and student details form
card.html    - Generated front and back ID card page
style.css    - Website and ID card styling
script.js    - Course selection, roll number generation, and card data logic
README.md    - Project documentation
```

## How To Run

Open `index.html` in a browser.

Fill the form, select a template, upload a photo, and click:

```text
Create Front & Back ID Card
```

The generated ID card will open in `card.html`.

## Roll Number Format

Example:

```text
B25CS094
```

The roll number is generated from degree, admission year, course code, and serial number.

## Free Hosting

You can publish this website for free using GitHub Pages.

1. Create a GitHub repository.
2. Upload these files:
   ```text
   index.html
   card.html
   style.css
   script.js
   README.md
   ```
3. Go to repository `Settings`.
4. Open `Pages`.
5. Select:
   ```text
   Source: Deploy from a branch
   Branch: main
   Folder: /root
   ```
6. Click `Save`.

Your website link will look like:

```text
https://your-github-name.github.io/repository-name/
```
